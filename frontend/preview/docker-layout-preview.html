以下为三种不同风格的布局演示，用于对比和选择

特点：
  • ✓ 图标按钮大幅节省横向空间，小屏幕也不换行
  • ✓ 元信息（镜像ID/容器ID）单行紧凑排列，视觉噪音少
  • ✓ 操作按钮有 hover tooltip，不占空间也不影响理解
  • ✓ 星标容器用绿色调+绿色名称高亮，视觉区分清晰
  • △ 纯图标需要学习成本（但 tooltip 缓解）

  • △ 视觉上偏"工具化"，不如卡片友好
